# GPT Calculator

A simple desktop calculator application built with Java Swing.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers
- Percentage calculation
- Sign toggle (`+/-`)
- Delete last digit
- Clear/reset
- Division-by-zero handling

## Requirements

- Java 17 or newer
- Maven 3.8+

## Build

```bash
mvn clean package
```

## Run

```bash
java -jar target/gpt-calculator-1.0.0.jar
```
